# Лабораторные работы по Python, вариант 14

## Запуск в PyCharm
1. File -> Open -> выбрать папку `labs_var14`.
2. Настроить интерпретатор (Python 3.11+), при желании создать `.venv`.
3. Запустить `main.py` (общее меню) или `lab1/main.py` напрямую.

## Лаба 1
Вариант 14: извлечение чисел из строки, содержащей числа и буквы.
Модули не импортируются, используется lambda (`extract_numbers`).

## Лаба 2
Вариант 14: визуализация и спектральный анализ речевого сигнала.
- Тип графика отсчётов: столбчатая диаграмма.
- Тип спектрального анализа: квадрат ДПФ (Re^2 + Im^2).
- Частота дискретизации: 11025 Гц.
- Файл записи: `lab2/data/14.wav` (можно указать свой путь при запуске).

Зависимости: `numpy`, `scipy`, `matplotlib` (см. `requirements.txt`).
При запуске откроются 4 окна с графиками: чтение отсчётов, осциллограмма,
спектр, гистограмма.

## Лаба 3
Вариант 14: стеганография.
- Задание 1.1: декодирование сообщения из синего канала пикселей
  (`lab3/data/new14.png` + `lab3/data/keys14.txt`). К результату
  автоматически добавляется "I trust AI".
- Задание 1.2: кодирование/декодирование методом **b1-R, b0-R**
  (2 младших бита красного канала, 4 пикселя на символ). Координаты
  генерируются случайно и сохраняются в `lab3/output/`.
- Сообщение для кодирования вводится с клавиатуры на русском языке.
  Чтобы вписать своё ФИО прямо в код, замените константу
  `DEFAULT_MESSAGE` в начале `lab3/main.py` - тогда его можно будет
  принять просто нажатием Enter.

Зависимость: `Pillow` (см. `requirements.txt`).

## Лаба 4
Вариант 14: Telegram-бот, который здоровается в зависимости от времени
суток.
- Username бота: `ist_24_2_var14_bot`.
- Час запрашивается с сайта worldtimeapi.org (парсится регулярным
  выражением); если сайт недоступен, используется локальное время
  по часовому поясу Europe/Moscow, чтобы бот не падал.
- `/start` - приветствие по имени и времени суток, с кнопкой
  «Поприветствуй меня» (минимум ввода с клавиатуры).
- `/help` - справка с грустным смайликом 😢, как требует задание.

**Перед запуском:** создайте файл `.env` в корне проекта (рядом с этим
README) со строкой:
```
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
```
Пример - в `.env.example`. Файл `.env` уже в `.gitignore` и не попадёт
на GitHub.

Зависимости: `python-telegram-bot`, `requests`, `python-dotenv`
(см. `requirements.txt`).
